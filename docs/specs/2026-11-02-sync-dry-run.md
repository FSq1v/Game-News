# 仕様書: まとめ記事の取り込みに --dry-run を足す
- 状態: 確定
- 作成: 2026-11-02
- 種類: 受託

## 目標
scripts/sync_digests.py に --dry-run を足す。付けて動かすと、何も書き出さずに、今の報告（新規・上書き・変更なし・スキップ）と、上書きになるノートの差分を表示する。push の前に「何が変わるか」をその場で確かめられるようにする。

## 受け入れの条件
- AC1: --dry-run を付けると、書き出し先のファイルが1つも作られず、書き換えられもしない（確かめ方: テスト）
- AC2: --dry-run でも書き出し先のフォルダが無ければ作らない（確かめ方: テスト）
- AC3: --dry-run の報告の行は、付けないときと同じ「新規・上書き・変更なし・スキップ」の判定になる（確かめ方: テスト）
- AC4: 上書きになるノートには、今のファイルと書き出す予定の中身の unified diff が報告のあとに出る。変更なし・新規・スキップのノートには差分を出さない（確かめ方: テスト）
- AC5: --dry-run のときは、報告の最後に「書き出していません（--dry-run）」と1行出る（確かめ方: テスト）
- AC6: --dry-run を付けないときの動きと出力は今と変わらない（今のテストがそのまま通る）（確かめ方: テスト）

## やらないこと
- 新規のノートの中身の表示
- 色つきの差分
- README 以外の文書の書き換え

- Q2: README の「まとめ記事の取り込み」に使い方を1行足すか（扱い: 仮で進める。仮の答え: 足す）
